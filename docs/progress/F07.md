# F07 - Paths y diseno avanzado

## F07-WP01 (en curso)

- Se incorporo `parseSvgPathData` como fuente unica de validacion para paths
  creados por el MCP. El AST conserva case de comandos, subpaths y comandos
  relativos; la repeticion implicita de moveto se normaliza a lineto segun SVG.
- `serializeSvgPathData` rechaza aridades y valores no finitos antes de emitir
  una representacion compacta y determinista. La cobertura incluye todas las
  familias de comando y flags de arco.
- La edicion publica de nodos, combine/break-apart/reverse y booleanas aun no
  se anuncia: depende de preservar indices, refs y la politica de snapshots.
- `paths_combine` y `path_break_apart` ya se publican con revision esperada,
  IDs tipados y rechazo de referencias rotas. `path_reverse` invierte líneas,
  curvas cúbicas/cuadráticas, smooth commands y arcos sin aproximarlos;
  conserva el ID/estilo y normaliza el resultado a SVG absoluto.
- `paths_boolean` ejecuta el motor nativo de Inkscape en un input temporal y
  publica sólo el SVG exportado que supera sanitización. Union, difference,
  intersection y exclusion se limitan a dos IDs seguros; faltan los fixtures
  de área y la semántica explícita de diferencia para cerrar esta capacidad.
- `gradients_manage` entrega CRUD tipado de gradientes linear/radial y stops,
  además de aplicación a fill o stroke. Las referencias `url(#id)` se validan
  al borrar; no se admite XML, CSS ni colores libres.
- `patterns_manage` entrega CRUD tipado de patrones dots/stripes, aplicables a
  fill o stroke, con unidades y matrices invertibles. Sus colores, tamaños y
  referencias se validan antes del commit; no acepta XML ni CSS libre.
- `markers_manage` entrega CRUD de markers de flecha/punto y su aplicación en
  inicio, medio o final de líneas y paths. El API limita explícitamente los
  destinos y no admite path data libre; pruebas unitarias y MCP lo cubren.
- El saneador conserva filtros SVG locales desconocidos y sus referencias, por
  lo que una operación de diseño no destruye efectos que todavía no son
  editables mediante el API; URLs de filtro externas permanecen rechazadas.
- `metadata_manage` añade title, description y licencia documental, junto con
  labels, nombres y ocultación ARIA por elemento. Sólo acepta texto plano
  acotado; RDF arbitrario y heurísticas de contraste siguen fuera del API.
- `text_path_manage` permite attach/detach de text-on-path sin convertir el
  texto: reubica los nodos de texto y tspan dentro del `textPath` y conserva
  el ID del texto. La conversión irreversible a paths sigue separada.
- `objects_to_paths` convierte rect/circle/ellipse/line/polygon/polyline/path
  seleccionados —o sus trazos— mediante acciones nativas en staging; exige
  revisión, confirmación explícita y publica backup, diff y warning
  irreversible. El smoke MCP real verifica `object-stroke-to-path`.
- `path_effects_inspect` inventaría efectos de trayecto locales y los paths que
  los referencian sin interpretar ni modificar parámetros LPE; la edición se
  mantiene deshabilitada hasta disponer de fixtures headless por tipo.
- `connector_retarget` conserva la ruta de un conector Inkscape existente y
  reemplaza únicamente sus dos referencias locales de endpoints, con revisión
  y backup; routing y follow-after-move siguen pendientes.
- `connector_route` recalcula una polilínea ortogonal por centros de rect,
  circle o ellipse y respeta transformaciones axiales directas; conserva las referencias Inkscape. No
  anuncia evitación de obstáculos ni seguimiento automático tras mover objetos.
- `palette_inspect` inventaría colores hex directos, variables CSS locales y
  swatches sólidos nombrados de Inkscape; `palette_apply` actualiza un mapa
  explícito en atributos, valores de variables y stops, con revisión y backup.
  Gradientes multistop y colores indirectos complejos permanecen gateados.
- `color_management_inspect` informa perfiles SVG locales y referencias
  `icc-color()` sin afirmar conversión CMYK ni validación de output intent;
  PDF/X y preprensa externa permanecen explícitamente gateados.
- `flowed_text_inspect` localiza roots flowed y párrafos; `flowed_text_convert`
  convierte únicamente el caso simple de una región a texto SVG editable tras
  confirmación de pérdida. Flows complejos se rechazan para no simular layout.
- `path_node_move` mueve endpoints absolutos de líneas, curvas y arcos; y
  `path_node_edit` inserta/elimina nodos lineales, cambia L/T, abre/cierra un
  subpath y edita handles Q/C o parámetros de arco. `expand_smooth` convierte
  S/T a C/Q equivalentes para exponer sus handles reflejados. Los comandos
  relativos se normalizan a SVG absoluto equivalente; falta estabilidad de
  índices tras transformaciones complejas.
- `images_crop` aplica un `clipPath` local en unidades de usuario sobre una
  imagen SVG, sin rasterizar ni modificar su `href` o geometría. Requiere una
  revisión actual y rechaza reemplazar silenciosamente un clip existente; la
  cobertura unitaria y de cliente MCP verifica el flujo completo.
- `clips_manage` extiende el uso de clips a cualquier elemento: crea un
  rectángulo tipado, lo aplica o libera por IDs explícitos y rechaza borrar un
  recurso aún referenciado por SVG o CSS. `masks_manage` proporciona el mismo
  ciclo para una máscara rectangular opaca en espacio de usuario, sin permitir
  XML libre; ambas herramientas tienen cobertura unitaria y por cliente MCP.

## F07-WP06 (2026-08-27)

- `symbols_manage` lista, crea y elimina símbolos locales, y crea clones
  `<use>` con posición opcional. Verifica IDs, ausencia de referencias y la
  ausencia de ciclos antes de mutar; no abre una vía para XML arbitrario.
- `guides_grids_manage` ofrece inspección y CRUD tipado de guías y cuadrículas
  `xygrid` dentro de `sodipodi:namedview`. No toca preferencias globales de
  Inkscape y conserva revisiones/backup atómico en cada mutación.
- Evidencia: `npm run check` completó formato, lint, tipos y 177 pruebas
  unitarias (una omitida); `npm run test:mcp` completó las comprobaciones MCP
  modernas y legacy por stdio, incluidas ambas herramientas nuevas.
