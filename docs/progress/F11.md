## F11-WP02 (2026-08-27)

- `inkscape-mcp export` permite a PowerShell y automatizaciones locales ejecutar
  un preset sin un cliente de IA: inspecciona el SVG para tomar su revisión,
  solicita `document_export_preset_plan` y sólo después consume ese plan en
  `document_export_batch` atómico.
- Sus únicos argumentos propios son `--source`, `--preset`,
  `--output-directory`, `--workspace-index` y `--dry-run`; las rutas de
  documento y salida siguen siendo relativas y se validan antes de iniciar el
  hijo stdio. Los flags de configuración permitidos se reenvían sin ampliar el
  contrato público del servidor.
- `--dry-run` devuelve digest, vencimiento y outputs previstos sin crear el
  directorio destino. El smoke real crea un SVG temporal, verifica ese corte y
  luego comprueba el PNG publicado por `web-png`.
- Evidencia: `npm run check` completó 183 pruebas (una omitida) y `npm run
test:cli` superó la exportación real con Inkscape.

## F11-WP03 (2026-08-27)

- `inkscape-mcp run receta.json` carga únicamente recetas JSON
  `inkscape-mcp-recipe/v1` con `source`, `workspaceIndex` y operaciones
  estrictas `inspect`, `preflight` o `export`; no admite XML, actions, shell ni
  rutas de documento/output absolutas.
- La ejecución abre una sola sesión MCP privada, toma una revisión de fuente y
  crea todos los planes antes de consumir cualquiera. Rechaza colisiones entre
  outputs de exportación antes de publicar. Cada salida de export conserva el
  lote atómico del servidor; el recibo `inkscape-mcp-recipe-receipt/v1` incluye
  digest, outputs, manifiesto y resultados por operación.
- Los errores de receta tienen código de proceso `2`; los fallos MCP/runtime,
  `3`; el éxito, `0`. Los tokens internos no se exponen porque expiran con el
  proceso que ejecuta la receta.
- Evidencia: `npm run check` completó 185 pruebas (una omitida), `npm run
test:cli` verificó inspect, preflight no publicante y export real de una
  receta temporal, y `npm run test:pack` ejecutó la receta desde el `.tgz`
  instalado sin el árbol fuente.

## F11-WP04 (2026-08-27)

- `Invoke-InkscapeMcpRecipe.ps1` resuelve literalmente receta, workspace,
  binario Node y CLI, ejecuta `run` con argumentos separados, escribe un log
  local y propaga el código de salida. `-NonInteractive` evita progreso y
  prompts de PowerShell; no abre Inkscape en GUI.
- `Register-InkscapeMcpDailyTask.ps1` sólo registra una tarea si el operador lo
  invoca y confirma (soporta `-WhatIf`). Usa el principal `Interactive` del
  usuario actual, `powershell.exe -NoProfile -NonInteractive` y el runner
  anterior: no guarda contraseñas ni habilita red/HTTP.
- Ambos scripts se incluyen en el `.tgz`; el smoke Windows analiza su sintaxis
  PowerShell, ejecuta un runner real con receta, ruta con espacios y log, y
  ejercita el registro de la tarea únicamente con `-WhatIf`.
