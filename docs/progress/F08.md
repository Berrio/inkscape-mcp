# F08 — Importación, formatos adicionales, presets y paquetes

## F08-WP01 (en curso)

- `document_import_svg` incorpora un SVG existente del workspace a un output
  nuevo, con revisión esperada y commit atómico.
- El importador llama al sanitizador antes de publicar y respeta el máximo de
  política configurado; por tanto no permite elevar preserve-local a trusted.
- La integración MCP crea un SVG con `<script>` y `onclick`, aporta el SHA-256
  crudo del archivo (un documento hostil no tiene que ser inspeccionable para
  importarse) y comprueba que el SVG destino conserva el rectángulo permitido
  pero no el script ni el event handler.
- `assets_package` publica `document.svg`, las dependencias locales reescritas
  bajo `assets/`, y `manifest.json` con revisiones SHA-256. Reutiliza la
  cuarentena de entrada nativa: no sigue rutas absolutas, externas ni fuera del
  workspace, limita cada recurso y comprueba revisiones antes de publicar.
- La prueba MCP comprueba los bytes copiados, URI reescrito y manifiesto de un
  paquete con una dependencia local. SVGZ, raster, PDF, fuentes y perfiles
  siguen pendientes como adaptadores de importaciÃ³n.
