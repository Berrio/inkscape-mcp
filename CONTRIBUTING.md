# Contribuir

Gracias por tu interés. El proyecto está en pre-alpha y se implementa siguiendo [PLAN_IMPLEMENTACION.md](./PLAN_IMPLEMENTACION.md).

## Reglas de trabajo

1. Lee `AGENTS.md` y el plan completo antes de modificar código.
2. Trabaja en un único work package por cambio.
3. Añade o actualiza pruebas y registra evidencia en `docs/progress/FXX.md`.
4. No expongas comandos, argumentos de Inkscape ni rutas arbitrarias a clientes MCP.
5. No reduzcas límites o pruebas de seguridad para hacer pasar una fase.

## Cambios propuestos

Abre una issue antes de cambios de arquitectura, contratos públicos, permisos, formatos o dependencias relevantes. Las decisiones de licencia, publicación y seguridad se documentan como ADRs durante la fase correspondiente.
