# F05 - Exportaciones

## F05-WP03 (inicio)

- `export_pdf` usa `pdf-lib` 1.17.1 (MIT) para rechazar PDFs no parseables y
  devolver version, numero de paginas y MediaBox por pagina; la prueba crea un
  PDF de dos paginas con boxes conocidos y el flujo MCP verifica un PDF real
  de Inkscape.
- Aun falta la sonda multipagina especifica de Inkscape 1.4.4, CropBox,
  tolerancias, subset, LaTeX y contratos completos de opciones PDF.
