## F00-WP01

- Objetivo verificable: establecer la identidad pública mínima y un repositorio Git limpio, sin iniciar la implementación del servidor.
- Prerrequisitos/puertas: el usuario autorizó nombre `inkscape-mcp`, licencia MIT, commit inicial y publicación pública.
- Interfaces disponibles: únicamente documentación; no hay runtime, paquete ni herramientas MCP.
- Archivos/artefactos esperados: configuración de Git, documentación base y este informe.
- Tareas condicionales permitidas: `F00-T07` solo tras revisar los archivos y el índice Git.

### Decisiones

- Nombre público propuesto y aceptado: `inkscape-mcp`.

- Publicación: repositorio Git público cuando se confirme un remoto GitHub autenticado.
