# F09 — Contrato MCP, progreso y jobs

## F09-WP03 (2026-08-27)

- `job_get` y `job_cancel` conservan ownership por workspace y la cancelación
  es idempotente: una segunda petición devuelve el snapshot terminal sin crear
  otro trabajo ni exponer resultados parciales.
- `scripts/test-mcp.mjs` somete un export PNG real como job, lo cancela, espera
  estado `cancelled`, verifica que no se publicó el archivo y repite la
  cancelación para fijar el contrato.
- `tests/unit/jobs.test.ts` cubre además un trabajo completado: cancelarlo no
  elimina ni altera su recibo terminal.

## F09-WP05 (2026-08-27)

- El transporte stdio emite únicamente eventos JSON estructurados y
  redaccionados por stderr al escuchar o al recibir un error; stdout queda
  reservado al framing MCP.
- ESLint prohíbe `console` en TypeScript de producto/pruebas, y una prueba fija
  la redacción de tokens y rutas Windows antes de escribir el diagnóstico.
