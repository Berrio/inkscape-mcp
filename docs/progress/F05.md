# F05 - Exportaciones

## F05-WP03 (inicio)

- `export_pdf` usa `pdf-lib` 1.17.1 (MIT) para rechazar PDFs no parseables y
  devolver version, numero de paginas y MediaBox por pagina; la prueba crea un
  PDF de dos paginas con boxes conocidos y el flujo MCP verifica un PDF real
  de Inkscape.
- Aun falta la sonda multipagina especifica de Inkscape 1.4.4, CropBox,
  tolerancias, subset, LaTeX y contratos completos de opciones PDF.

## F05-WP02 (en curso)

- `export_png` acepta DPI explicito de 0 a 9600 y lo envia mediante el flag
  allowlisted de Inkscape. Rechaza mezclar DPI con width/height para no ocultar
  la precedencia del motor.
- El verificador PNG inspecciona IHDR y, cuando existe, `pHYs`, devolviendo DPI
  X/Y observado. La integracion MCP exporta un PNG a 144 DPI desde Inkscape.
- PNG admite `background=document|transparent|solid`. `document` usa
  `pagecolor`/`pageopacity` y nunca el desk; `solid` exige color hexadecimal y
  puede definir opacidad. La integracion MCP valida una exportacion roja.
- PNG declara `area=page|drawing` y pasa solo `--export-area-page` o
  `--export-area-drawing`; un documento sin objetos no tiene drawing exportable,
  por lo que la integracion valida page y deja la fixture visible para la prueba
  de drawing junto al motor de elementos.
- `export_svg` acepta `textToPath` de forma explicita y devuelve
  `TEXT_CONVERTED_TO_PATHS`; el test MCP cubre el flag para que la conversion
  no quede silenciosa.
