# F06 - Motor de elementos y diseno basico

## F06-WP02 (inicio)

- `elements_create` crea batches de 1 a 100 rects (incluidos rounded),
  circles, ellipses, lines, polylines y polygons mediante schemas tipados.
- Cada forma valida finitud, rangos, color hexadecimal seguro y IDs sin
  espacios/controles; las colisiones se rechazan y las mutaciones usan revision
  esperada, backup y commit atomico.
- La integracion MCP crea un rectangulo rojo y lo exporta mediante
  `area=drawing` con Inkscape real.
- El mismo schema crea texto escapado como contenido de nodo, no markup, con
  tipografia inicial `fontFamily`, `fontSize`, `fontWeight` y `textAnchor`.
- El batch admite `group` y `layer` con ID/label; los elementos posteriores
  pueden indicar `parentId` de un grupo/capa existente o creado antes, sin
  reparenting libre ni referencias hacia adelante.
- `elements_delete` borra IDs explicitamente seleccionados y adopta una politica
  conservadora: rechaza el batch si una referencia `href` de un elemento que
  queda vivo se volveria rota.
- `elements_transform` acepta solo transformaciones numericas tipadas
  translate/scale/rotate/skew/flip/matrix y las anexa al transform existente;
  no acepta cadenas SVG arbitrarias ni matrices singulares.
- `elements_query` devuelve resúmenes en orden documental por IDs, tipo o capa,
  con `limit`/`offset` acotados y `missingIds` para distinguir IDs ausentes.
  Por ahora no interpreta CSS, no calcula estilos ni bounds, y no llama a las
  queries nativas de Inkscape.
- Pendiente: selectores CSS, estilos/bounds, paths, imágenes, updates,
  arrange y transacciones de operaciones heterogeneas.
