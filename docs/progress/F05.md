# F05 - Exportaciones

## F05-WP01 (completado el 2026-08-26)

- `exportSpecSchema` implementa el contrato discriminado por formato para PNG,
  PDF, SVG/plain SVG/SVGZ y formatos adicionales gateados. Rechaza propiedades
  cruzadas, áreas custom fuera de PNG, selección/páginas múltiples sin destino
  de directorio, templates inseguros, rutas absolutas/traversal y overwrite sin
  la revisión de salida esperada.
- `ExportAreaNormalizer` se amplió para page, drawing, selección única y área
  custom. La planificación de múltiples páginas o selección `each` queda
  explícita para el planificador de variantes de F05-WP05: nunca se convierte
  en un argv ambiguo.
- Los builders puros generan únicamente flags allowlisted desde el spec ya
  validado. El pipeline común emite etapas ordenadas
  `validated→staging→rendering→verifying→publishing→completed`, propaga
  cancelación y garantiza cleanup del staging del adaptador.
- El manifiesto común registra request normalizado, versión Inkscape, hashes de
  artefactos, estrategia y warnings sin rutas absolutas. `ArtifactStore` admite
  metadata de formato/verificación y publicación de lote opaca con rollback
  de copias si falla un miembro; no se describe como atómica ante crash.
- El dispatcher de verificación solo acepta PNG/PDF/SVG/plain-SVG cuando puede
  probar su estructura. Los demás formatos devuelven falta de verifier hasta
  tener capability, fixture y adaptador real.

- `npm run test:mcp` pasó con Inkscape local y los transportes moderno/legado.

## F05-WP03 (completado el 2026-08-26)

- `export_pdf` usa `pdf-lib` 1.17.1 (MIT) para rechazar PDFs no parseables y
  devolver versión, número de páginas, MediaBox, CropBox, bytes y SHA-256.
  La prueba unitaria crea un PDF de dos páginas con boxes conocidos y el flujo
  MCP verifica un PDF real de Inkscape.
- En Inkscape 1.4.4, la exportación completa omite `--export-page` y conserva
  todas las páginas en un solo PDF (`full_document`). Un subset genera una
  copia SVG inmutable podada por IDs de página, la exporta como documento y
  comprueba el conteo solicitado (`prune_subset`).
- `latex=true` está capability-gated y exige el sidecar generado por Inkscape.
  El PDF y `output.pdf_tex` se publican con `AtomicFileStore.commitBatch` bajo
  los mismos locks y revisión del origen. Si una publicación manejada falla,
  se restauran los miembros ya renombrados; esa garantía no se presenta como
  atomicidad ante un crash del proceso. La respuesta expone solo la ruta
  relativa y revisión del sidecar, con `LATEX_SIDECAR_EMITTED`.
- `export_pdf_pages` cubre páginas separadas. Recibe solo IDs de página y un
  directorio relativo existente; cada salida se llama `page-NNN.pdf` según la
  posición original de la página, no el orden de la petición. Genera y verifica
  todos los PDFs antes de publicarlos mediante el commit lógico del grupo.
- El margen PDF no depende de `--export-margin`: en 1.4.4 se expande una copia
  temporal del viewport o de las páginas explícitas y se valida la caja
  producida. El flujo MCP medido para una página A4 ampliada 5 mm por lado
  devuelve 624 × 871 pt; la respuesta declara
  `PDF_MARGIN_EXPANDED_TEMPORARY`.
- La integración MCP usa dos páginas de anchos distintos para confirmar el
  orden del PDF completo y de un subset solicitado en orden inverso. También
  exporta `pdf-nonzero-viewbox.svg` y verifica MediaBox/CropBox 284 × 142 pt
  con la tolerancia de ADR-011; esta build no reproduce el problema 6323.
- ADR-011 registra la sonda de Inkscape 1.4.4: una exportación sin
  `--export-page` conserva un PDF multipágina, mientras que `--export-page`
  crea archivos `_pN.pdf` separados. El subset será poda de una copia SVG; la
  tolerancia de boxes es 0.6 pt y el fixture de viewBox no cero no activa
  workaround en esta build.
- El verificador PDF ahora publica CropBox, bytes y SHA-256. Version, texto a
  paths e ignorar filtros se capability-gatean; `filterDpi` se rechaza antes de
  ejecutar porque la ayuda de esta instalación no anuncia su flag.

## F05-WP02 (completado el 2026-08-26)

- `export_png` cubre áreas page, drawing, selection y custom; la selección se
  comprueba contra el SVG antes de crear el proceso nativo. DPI es mutuamente
  excluyente con píxeles; una dimensión conserva ratio y las dos requieren
  `allowDistortion=true`.
- El fondo admite `document|transparent|solid`: document obtiene únicamente
  `pagecolor`/`pageopacity` y no el desk. Opacidad, snap y todas las opciones
  PNG se convierten desde tipos acotados a flags allowlisted.
- Color mode (Gray/RGB/GrayAlpha/RGBA de 1 a 16 bits), dithering, compresión,
  antialias y snap se consultan en `CapabilityService` antes de la ejecución.
  Una capability ausente responde con un error recuperable y nunca con un flag
  especulativo.
- `verifyPng` entrega firma/IHDR validado, dimensiones, bit depth, color type,
  pHYs/DPI si existe, bytes y SHA-256. La salida MCP declara esta metadata en
  lugar de inferirla desde la solicitud.

- `npm run test:mcp` pasó en los transportes moderno y legado con Inkscape
