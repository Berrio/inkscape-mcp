- Interfaces disponibles: únicamente documentación; no hay runtime, paquete ni herramientas MCP.
- Archivos/artefactos esperados: configuración de Git, documentación base y este informe.
- Tareas condicionales permitidas: `F00-T07` solo tras revisar los archivos y el índice Git.
- No-objetivos: instalar dependencias, crear `package.json`, publicar npm, implementar el servidor o avanzar a F00-WP02.

## F00-WP02

- Objetivo verificable: crear un package ESM TypeScript reproducible con el SDK MCP v2, un binario mínimo y pruebas del paquete instalado.
- Prerrequisitos/puertas: `F00-WP01` cerrado.
- Interfaces disponibles: CLI de bootstrap sin servidor MCP funcional.
- Archivos/artefactos esperados: `package.json`, lockfile, configuración TypeScript/lint/formato, `src/cli.ts`, prueba unit y smoke test del `.tgz`.
- No-objetivos: registrar tools MCP, ejecutar Inkscape, publicar npm o habilitar HTTP.

### Decisiones técnicas

- Runtime: Node `24.18.0`; `engines` restringe Node 24 y npm 11–12.
- SDK: `@modelcontextprotocol/server` y `@modelcontextprotocol/client` `2.0.0`; Zod `4.4.3`.
- TypeScript: `6.0.3`, no 7.0.2, porque `typescript-eslint` `8.68.0` declara compatibilidad hasta TypeScript 6.0.x. No se usó `--force` ni `--legacy-peer-deps`.
- El paquete se mantiene `private: true` hasta la autorización de publicación npm de F11; el repositorio Git sí es público.

### Verificación ejecutada

```powershell
npm ci --no-audit --no-fund
npm run check
npm run pack:check
npm run test:pack
```

- `npm ci`: correcto desde lockfile, 321 paquetes instalados.
- `npm run check`: formato, lint, typecheck y 2 pruebas del CLI correctos.
- `npm run pack:check`: el tarball contiene solo `dist`, `README.md`, `LICENSE`, `SECURITY.md` y metadata npm.
- `npm run test:pack`: instalación aislada y ejecución del shim `inkscape-mcp --version` correctas.
- npm dejó sin ejecutar el postinstall opcional de Inspector a la espera de aprobación explícita de scripts; no es requerido para el binario ni se habilitó de forma implícita.

### Resultado

`F00-WP02` está cerrado. El siguiente WP permitido es `F00-WP03` (ADRs y manifest de fixtures).
