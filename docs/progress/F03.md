# F03 — Documentos, unidades, viewBox y páginas

## F03-WP01 (en curso)

- ADR-010 fija 96 CSS px/in, separación de viewport físico y user units, y `preserve_user_scale` como política `page_only` por defecto.
- `geometry` modela longitudes físicas/CSS, páginas, rectángulos de usuario y matrices de resize explícitas.
- Los vectores normativos A4, contain y cover se prueban con tolerancias de punto flotante. El escalado DOM/CSS avanzado no se anuncia aún.
- `createSvgDocument` genera SVG con namespaces y `viewBox` coherente; `resizePageOnlySvg` actualiza página/viewBox sin transformar elementos.
- El catálogo MCP ya expone `workspace_list`, `workspace_list_documents` y `document_create` con schemas estrictos. `test:mcp` crea un A4 en un root temporal por stdio sin paths absolutos.
- `document_resize` implementa `page_only` con `expectedRevision`, backup, commit atómico y nueva revisión; la integración stdio confirma A4 → 148 × 210 mm sin modificar elementos.
- El primer pipeline `export_png` ya usa staging, runner seguro, opciones allowlisted, verificación PNG/IHDR y commit atómico. La integración local exportó 400 px con Inkscape MSIX 1.4.4; su contrato completo se ampliará en F05.
- `export_pdf` aplica el mismo pipeline y valida `%PDF-x.y`; la integración MCP real exportó PDF 1.5 con la instalación MSIX. Inspección de page count/boxes y multipágina siguen planificados en F05.
